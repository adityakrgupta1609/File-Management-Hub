# File Management System

A Python-based File Management application built using **Streamlit**, providing a simple and interactive web interface for file management operations.

## Features

- User-friendly web interface powered by Streamlit
- File management through Python
- Interactive application interface

## Technologies Used

- Python
- Streamlit
- VS Code
- Git & GitHub

## Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/adityakrgupta1609/File-Management-Hub
```

**2. Navigate to the project directory**

```bash
cd File-Management
```

**3. Create a virtual environment**

```bash
python -m venv .venv
```

**4. Activate the virtual environment**

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

**5. Install dependencies**

```bash
pip install -r requirements.txt
```

**6. Run the application**

```bash
streamlit run FileHandlingApp.py
```
